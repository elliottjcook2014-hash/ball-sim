# The ball sim
## This is a Pygame ball simulation.
Everything is a class, like the balls, the ring, and everything else!
Edit the properties to your liking, and if you don't know how to code, just edit the constants at the top.
If you want to hack the project a little, go into the code a bit and see what you can add or change (like duplicate a ball or shrink the ring)
Have fun!
